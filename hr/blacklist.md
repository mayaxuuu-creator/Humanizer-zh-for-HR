# HR 与经营文本 AI 味黑名单

模式清单是检查线索，不是机械替换表；每个命中都要回到上下文。命中后优先"说清楚具体动作/数据"，而不是换一个同义套话。

## 词级黑名单

| AI 腔 | 处理方式 | 示例 |
|---|---|---|
| 值得注意的是 | 删，直接说 | "值得注意的是，续约率下降" → "续约率掉了6个点" |
| 综上所述 / 总而言之 | 删，直接给判断 | → "项目收口：目标达成2个，脱靶1个" |
| 首先/其次/最后（段首） | 换真实逻辑或直接分点 | 顺序真实存在时保留 |
| 深入分析后发现 | "数据里有个点比较反常" / 直接说发现 | |
| 在此背景下 | 删（读者知道背景） | |
| 随着……的不断深入/发展 | 删，直接说事 | |
| 至关重要 / 意义重大 | "最要紧的是" 或删 | |
| 有助于 | 能 / 可以 | |
| 进一步优化 / 提升 | 说清楚改什么、怎么衡量 | → "把月度校准从季度改到月度" |
| 整体向好 / 稳中向好 | "状况还行，但还需要注意X" | |
| 显著提升 / 大幅改善 | 给数字，或"比较明显" | |
| 形成闭环 | 说清楚从哪到哪 | → "从目标设定到月度校准到年终复盘" |
| 赋能（正文） | 说清楚具体动作 | 标题标签可保留（如"数智化赋能"），正文不行 |
| 打通 | 说清楚连接什么和什么 | → "门店运营和市场共用一套门店分级数据" |
| 抓手 | 每篇最多1次，且必须紧跟具体动作 | → "以门店管理工具为抓手，做经销商动销数据周报" |
| 多维度 / 全方位 / 深层次 | 说清楚是哪几个维度 | |
| 某种程度上 / 在一定程度上 | 删，或换成真实限定 | |
| 旨在 | 删 | |
| 本报告将 / 本文将 | 删 | |
| 不仅仅……更是…… | 删假对比，保留提供信息的那半句 | |
| 既要……也要……更要…… | 三连递进改取舍：要什么、放什么 | |
| 确保（高频） | 换具体动作或删 | |
| 促进 / 推动（虚动词） | 换具体动词 | → "跑" "推" "查" "收" |
| 持续发力 / 不断深化 | 换具体动作 | |
| 伪引用（"多项调研表明""业界最佳实践"） | 给出真实出处，或改成"我们自己的观察是" | |

## 结构级黑名单

- **每段三句、段段等长**：打破均匀节奏，让重要段落长、过场段落短。
- **结论圆满无例外**：至少留一个"但是 / 还没想清楚 / 有个例外"。真实经营文本必然有未解决问题。
- **设问自答**（"那么，什么是组织韧性呢？"）：删。
- **排比三连收尾**：删，换成一个具体判断。
- **万能展望结尾**（"相信在大家的共同努力下……"）：换成下一步动作 + 时间 + 负责人。
- **匿名群体主语**（"大家" "各部门" "相关团队"）：点名谁干。真实文本的分工写法是"谁 Lead、谁共同承担、总部/大区各管什么"。
- **数据没有基线**：任何数字加对比（同比 / 环比 / 目标 / 其他大区）。
- **伪深度**：把常识包装成洞察（"人才是企业的核心竞争力"）。要么给出这家公司特有的观察，要么删。

## 白名单（真实经营文本的标志，不是 AI 味）

以下用法在人写的经营文档中常见且有价值，**不要**当作 AI 味清除：

- 动词开头的短促业务短语：夯实基盘、拉通、收口、有所不为、稳基盘。
- 双面坦率判断："过去有效但现在制约我们的" "虽有一定优势，但护城河不深"。
- 真实取舍句式："做什么、不做什么、什么时候做、如何验证"。
- 嵌入正式文档的口语判断："讲真心话、面对现实" "这个数挺意外" "需要分开看"。
- 工作场景英文词：initiative、ownership、one team、case for change、milestone、framing。标准是"团队真实在用的词汇"，不是装饰性英文。
- 诊断链结构：现状 → 挑战 → 突破点 → 战术选择。
- 电报体备注和真实的不确定表达："可能还是需要" "目前只看认证和加盟"。
